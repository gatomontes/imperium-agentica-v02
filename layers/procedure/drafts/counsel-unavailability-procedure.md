## Entry Conditions

Enter this procedure only when the cited Cognitive contracts supply:

```text
COUNSEL_REQUIRED
+ explicit Advisory Role Requirement
+ COUNSEL_UNAVAILABLE
+ affected decision and dependency scope
```

The procedure does not create those findings.

## Expected Sequence

1. Preserve the findings and affected scope in the mission-matched Curia record.
2. Withhold the affected substantive decision.
3. Request a `SEPARABLE_WORK` finding for any proposed continuation.
4. Select the applicable branch:
   - no separable work → keep dependent work withheld
   - separable work found → continue only the cited separable scope
5. Before issuing a hold, constraint, deferral, escalation, recall, or termination instruction, require an effective Authority finding for that exact action.
6. Hand only the authorized instruction to the responsibility already assigned to Muster.
7. Preserve the Capability Gap Record through the cited Cognitive contract.
8. Wait for one admitted resolution condition.
9. Return the affected matter to ordinary decision formation without predetermining its substance.

## Resolution Conditions

The withheld path may leave this procedure only when one of the following externally defined conditions is recorded:

- a suitable admitted Officer receives a matching Curia Session Assignment and supplies the required counsel
- the CEO supplies a `SEPARABLE_WORK` finding that removes the decision from the affected path
- the decision is no longer required
- an admitted escalation destination accepts the matter under effective authority
- an authorized recall or terminal path supersedes the need

## Authority-Unavailable Branch

If no effective grant supports the intended disposition:

1. do not issue that disposition
2. preserve `AUTHORITY_UNAVAILABLE` or the applicable AB-001 finding
3. remain inside the last already authorized mission condition or cited safe-state instruction
4. do not invent a safe state in this procedure

## Prohibited Procedural Inference

This procedure must not infer:

- competence from urgency
- authority from responsibility
- permission from an Executive Mandate vacancy
- correlation from similar mission content
- construction authority from a Capability Gap Record
- whole-mission suspension from one withheld decision
- resolution from elapsed time

## Exit

Exit when the affected decision has either:

- returned to competent decision formation
- been removed as unnecessary
- transferred through an admitted escalation path
- been superseded by an authorized terminal path

The exit does not determine the later substantive decision.
