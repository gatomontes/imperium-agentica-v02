# OP-DISPOSITION — Operative Package Lineage

## State Distinctions

- OP-CURRENT: active packaged Operative pointer.
- Historical package: prior immutable package version.
- Failed package: refused or unresolved package that cannot be activated.
- Activated Operative: a separate future state requiring explicit authorization.
- Mission-bound Operative: a separate Muster state.
- Deployed Operative: a separate downstream state.

Admission of a package does not create any of the downstream states.
