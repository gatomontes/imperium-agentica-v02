# Ideas

## Status

Pre-draft staging surface.

This file is not doctrine.

This file is not a backlog.

This file is not an archive.

It holds raw candidate ideas that have not yet earned their own draft artifact.

---

## Purpose

Some concepts are too unstable, vague, small, or early for `/drafts`.

They should not be lost.

They also should not receive filehood too early.

`ideas.md` exists to preserve those pressures without admitting structure around them.

---

## Lifecycle

An idea may remain here only while it has not yet earned a better home.

When an idea becomes a draft, it is removed from this file and relocated into `/drafts` or another justified location.

When an idea is rejected, merged, absorbed, superseded, or made obsolete, it is removed from this file.

This file should not preserve moved ideas merely for history.

The repository history already preserves movement.

---

## Entry Format

Use the smallest useful shape.

```text
## Idea: <short name>

Pressure:
<What tension, possibility, or concern caused this idea?>

Possible direction:
<What might this become if it earns draft status?>

Removal trigger:
<What would cause this entry to be deleted?>
```

Entries may be shorter if the idea does not yet justify the full shape.
