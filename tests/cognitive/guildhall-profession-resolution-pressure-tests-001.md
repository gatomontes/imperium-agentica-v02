# Guildhall Profession Resolution Pressure Tests 001

## Status

Theoretical A2.1 candidate suite. No live profession resolution, Garrison search, persona action, or external effect.

## Tests

| ID | Pressure | Required finding |
|---|---|---|
| GPR-001 | Native product and owner are challenged | Profession Specification remains Guildhall-owned |
| GPR-002 | Mission artifacts are incomplete or mismatched | exact Mission Identity, Mission Need, and approved Work Specification versions are required |
| GPR-003 | Profession is inferred from superficial cues | capability, judgment, domain, evidence, scope, and risk determine fit |
| GPR-004 | Competence or practice limits are vague | required competence and legitimate boundaries are explicit |
| GPR-005 | Adjacent or excluded professions are hidden | adjacency, contribution, exclusion, and rationale remain explicit |
| GPR-006 | Evidence, escalation, or professional risk is omitted | all are required in the exact specification |
| GPR-007 | Operator names a preferred profession | preference remains a hypothesis until exact fit is demonstrated |
| GPR-008 | Work irreducibly spans distinct professions | ambiguity blocks rather than creating a synthetic profession |
| GPR-009 | Resolution outcome is ambiguous | conformant, refused, and unresolved findings remain distinct |
| GPR-010 | Known defect or missing evidence is ignored | refused and unresolved both block search eligibility |
| GPR-011 | Derivation or correlation is incomplete | exact PB-001 derivation, citation, and correlation are required |
| GPR-012 | Profession Specification changes | new version, assessment, supersession, and suitability review are required |
| GPR-013 | Garrison handoff is inspected | only the exact conformant version with complete criteria is search-eligible |
| GPR-014 | Resolution absorbs downstream concerns | no inventory result, persona selection, doctrine, forging, testing, recruitment, or deployment |
| GPR-015 | Repository is compared | no production semantic, Authority, Procedure, Runtime, institution, or universal-layer change |

## Pass Condition

All fifteen pressures pass together.
