# Collegium → Guildhall Candidate-Assembly Review 001

This non-live review records the creation-side contract for converting an approved Work Specification into an ordered Guildhall profession queue.

Collegium determines the required professional composition. Guildhall owns the Profession Queue and resolves its items in order. A queue is a workflow sequence, not a collection of simultaneously activated personas.

The existing contract is conformant when every item identifies one profession, task cluster, and rationale; positions are contiguous and one-based; later professions cannot resolve before preceding conformant specifications; and queue identity and position propagate through downstream creation artifacts. Multiple professions are represented by one ordered queue, without introducing multi-persona coordination.

Malformed, underspecified, or skipped items remain unresolved and cannot be treated as valid downstream input. A queue does not select a human exemplar, admit a Persona, create an Operative, activate anything, or authorize deployment.

This is synthetic evidence only. Real-person data, live persona production, Garrison mutation, Operative instantiation, Recruitment activation, Runtime operation, credentials, deployment, and external effects remain closed.
