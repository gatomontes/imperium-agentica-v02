## Dependency Closure

```text
mission formation
→ profession and persona production
→ recruitment
→ mission assembly
→ Cortine boundary
→ Theatre return
→ Curia authority and counsel
→ closure
→ release
→ reporting and delivery
```

Authority, provenance, correlation, and non-authority rules cross this entire chain.

Examples:

- Curia depends on Lazaretto, Executive Mandate, standing roles, provider ledgers, counsel availability, and Muster.
- Mission closure depends on Curia, Theatre, Lazaretto, Executive Mandate, Muster, Armory, Locksmith, Scribes, and Secretariat.
- Concurrency isolation binds almost every mission-scoped artifact.
- The cognitive map and lifecycle define how these responsibilities compose.

Therefore, no reviewed operational cluster is independent enough to move alone without creating draft-to-production normative dependencies.
