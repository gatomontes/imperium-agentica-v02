## Tests

| ID | Pressure | Required finding |
|---|---|---|
| RMA-001 | Procedure invokes an exact Maintenance Instruction | The instruction has one canonical Cognitive origin with stable meaning |
| RMA-002 | Authority cites a Master Mason diagnosis | The diagnosis is independently identifiable, versioned, bounded, and citable |
| RMA-003 | Procedure labels maintenance eligible | Eligibility is not asserted before Procedure, Authority, correlation, effect-safety, mapping, and abort gates are evaluated |
| RMA-004 | Healthy condition requires no intervention | No maintenance direction or Runtime effect is manufactured |
| RMA-005 | Diagnosis supports maintenance but Authority is absent | Consequential action is withheld and the cognitive reason, safe state, and re-entry conditions remain expressible |
| RMA-006 | Diagnosis exposes structural change | Escalation preserves the exact condition and prohibited assumptions without Master Mason deciding the structural change |
| RMA-007 | Operating observations are assembled locally | An internal situation assembly is not forced into a canonical artifact without demonstrated transfer or citation |
| RMA-008 | Runtime prepares mechanics for an instruction | Maintenance intent remains distinct from the Runtime Control-Plane Plan |
| RMA-009 | Runtime receives an undefined required artifact | Runtime refuses closed rather than inventing meaning |
| RMA-010 | Diagnosis or direction is transformed or superseded | PB-001 retains identity, lineage, correlation, and supersession ownership |
| RMA-011 | Prior external effect is indeterminate | No instruction silently repeats, compensates, or reinterprets the effect |
| RMA-012 | Maintenance succeeds operationally | No mission success, semantic correctness, closure, or release is inferred |
| RMA-013 | Bounded discretion is present | No autonomous repair or self-authorization is inferred |
| RMA-014 | Multiple Master Mason products require semantics | No universal Artifact layer is inferred merely from local artifact pressure |

## Pass Condition

All fourteen pressures must pass together.

A candidate that defines only `Maintenance Instruction` fails if diagnosis timing, withholding, escalation, or intent-versus-plan separation remains unresolved.
