# DR-012 — Human-Trait Canon Schema

## Status

Recorded decision; Human-Trait Canon schema and lifecycle admitted for current semantic use.

## Date

2026-07-25

## Decision

Imperium admits the Human-Trait Canon schema as the bounded cognitive artifact through which Hagiography may preserve EC-01-reviewed trait candidates for possible later Foundry review.

The Canon preserves exact evidence provenance, observed behavior, bounded trait interpretation, context, limitations, counterweights, conflicts, uncertainty, revision conditions, version lineage, and downstream restrictions.

Hagiography owns evidence review and canonization recommendation. Foundry may consume, reject, or return an exact canonized entry version during persona construction; Foundry does not canonize entries.

## Preconditions and Boundaries

- EC-01 and EC-CURRENT govern evidence-source discipline.
- EC-02 must be admitted before any real-person Human-Trait Canon entry is created or processed, unless a later explicit decision authorizes a bounded exception.
- Synthetic fixtures remain permitted for testing and do not create real-person records.
- An unresolved trait conflict blocks canonization.
- A bounded conflict requires explicit conditions, counterweights, affected entries, and a traceable disposition.
- Admission of this schema does not canonize a person or trait.

This decision does not create a Saint record, Human-Trait Canon entry, persona, Officer, Operative, Runtime behavior, recruitment package, deployment, or external effect.
