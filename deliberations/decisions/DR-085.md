# DR-085 — Castellan Mission-Formation Correction

Status: admitted successor correction; supersedes DR-084.

## Decision

Remove institutional judgment from Castellan's profile-admission and runtime
path. The doctrine-assigned Senator admits Castellan Profile v2 from exact
conformance evidence and authority lineage. No judging body is embedded in or
consumed by Castellan.

Castellan must issue an intent inquiry even when Secretariat intake appears
complete. The inquiry covers purpose, scope, constraints, acceptance criteria,
requested outputs, unknowns, material contradictions, and resource
requirements. Secretariat presents the questions, records Operator answers,
and issues the exact evaluation handoff.

The resident Castellan operating layer records one exact cognitive disposition
for each answered predicate: `RESOLVED`, `DECLARED_NONE`, `AMBIGUOUS`,
`CONTRADICTORY`, or `UNUSABLE`. Castellan forms a candidate Mission
Specification only from an exact matching assessment. Adverse determinations,
uncleared unknowns, and uncleared contradictions produce further inquiry.

## Corrections

- Eliminates the complete-intake deadlock and the forged-state test.
- Replaces nonblank-answer presence checks with explicit semantic dispositions.
- Prevents unknowns and contradictions from disappearing into an empty
  unresolved list.
- Distinguishes `DECLARED_NONE` from an actual constraint or resource.
- Requires exact current Secretariat profile lineage on dossiers and handoffs.
- Replaces nineteen generated boilerplate applications with nineteen specific
  Castellan doctrine applications.
- Adds Castellan reconstruction to the default test command.

## Evidence

- Castellan reconstruction: 9/9 PASS.
- Combined Castellan, Secretariat, profile, and Lexicon pressure set: 44/44 PASS.
- Blackquill correction review: `ACCEPTABLE` for the bounded non-live contract.
- Repository-wide TypeScript retains only the inherited transport-export and
  legacy Petition-fixture findings already classified by DR-070.

## Boundary

No research, profession selection, Persona construction, institutional
judgment, disposition, activation, deployment, supervision, execution,
Runtime, credential, provider, or external-action authority is introduced.
