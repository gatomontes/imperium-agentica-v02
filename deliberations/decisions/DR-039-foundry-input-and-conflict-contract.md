# DR-039 — Foundry Input and Conflict Contract

## Status

Active semantic contract proposal. Admission requires a separate synthetic pressure test. No implementation, Runtime action, persona production, Operative creation, activation, deployment, credential use, or external effect is authorized.

## Scope

Foundry receives an approved profession-resolution package from Guildhall, applicable Persona Governance Doctrine from Studium, and a canonized Human-Trait Canon entry from Hagiography. It integrates only those versioned inputs into a Persona Specification Candidate.

## Contract

1. Foundry accepts only identified, versioned, provenance-preserving inputs whose upstream gates are satisfied.
2. Guildhall’s approved Profession Specification establishes the professional target and retains profession-resolution authority.
3. Studium’s applicable Persona Governance Doctrine establishes permitted conduct, evidence, boundaries, and required constraints.
4. Hagiography’s canonized Human-Trait Canon entry supplies supported transferable traits; candidate or rejected entries are not acceptable inputs.
5. Source authority follows domain ownership: no input source may silently override another office’s authority.
6. Conflicts are recorded explicitly with the affected claims, versions, provenance, and governing owner. Foundry may reconcile only within its synthesis boundary; unresolved conflicts are returned to the responsible upstream office.
7. Missing, stale, contradictory, or unauthenticated inputs cause refusal or named return, never silent substitution or inference.
8. The resulting Persona Specification Candidate preserves source lineage, transformation rationale, unresolved matters, version identity, and the exact intended downstream recipient.
9. Revision or supersession of an upstream input invalidates or reopens the affected candidate according to the recorded dependency; Foundry does not conceal stale lineage.
10. Foundry hands Pit only a complete candidate satisfying release conditions. Pit’s qualification authority remains distinct from Foundry’s synthesis authority.

## Boundaries

Foundry does not determine professional fit, author Persona Governance Doctrine, canonize human traits, perform adversarial qualification, select a Canonical Persona, reserve Garrison inventory, recruit an Operative, activate, deploy, or create external effects.

This proposal is semantic only; admission and implementation require separate authorization.
