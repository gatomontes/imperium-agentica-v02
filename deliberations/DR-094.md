# DR-094 — Isolde Base Persona and Resident Agent Definition

Status: provisional implementation candidate.

## Decision

Separate Isolde's behavioral identity from her institutional binding.

The Isolde Base Persona defines provider-neutral reasoning and communication
behavior only. Release `0.1.0` is a generic provisional Persona: precise,
patient, literal, plain-spoken, one question at a time, and able to explain or
rephrase obscure wording without judging the Operator's response.

The Isolde Resident Agent Definition binds one exact immutable Base Persona
artifact version and SHA-256 digest to the exact admitted Secretariat Office
Profile. Capabilities, prohibitions, and Locksmith-owned provider selection live
in the Agent Definition rather than the Persona.

The existing Isolde Officer contract continues to carry constitutional office
constraints during this transition. The executable resident officer refuses to
initialize unless the admitted Base Persona, Agent Definition, Office Profile,
and Officer contract agree. Provider instructions are assembled from the pinned
Base Persona instead of duplicating Isolde's behavioral identity in adapter
prompt strings.

Persona upgrades never float into an existing Agent Definition. A new Persona
version must be admitted first; a new Agent Definition must then pin, validate,
and deliberately activate that exact version and digest.
