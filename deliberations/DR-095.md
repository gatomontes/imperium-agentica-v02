# DR-095 — Guildmaster Authority and Resident Agent

Status: provisional implementation candidate.

Guildmaster is Guildhall's resident chairman and the authoritative professional-
suitability decision maker. The Guildhall committee explores profession
possibilities; Guildmaster admits, consolidates, or rejects every proposal,
separates professions from capabilities and tool/access requirements, determines
queue sufficiency and collaboration order, and approves the resulting profession
queue.

Castellan owns the Mission Specification and checks returned work only for
mission-contract conformance. Rector remains Castellan's bounded analytical
agent and holds no Guildhall authority.

Guildmaster is assembled from an admitted Base Persona, Resident Officer
Contract, and Guildhall Office Profile through an exact Resident Agent
Definition. The live adjudication prompt derives from that Persona, and every
approved Profession Adjudication Packet records the exact Agent Definition used.

Guildmaster may not alter mission intent, select people, Personas, Operatives, or
Officers, plan or execute the mission, or access credentials.
