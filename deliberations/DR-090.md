# DR-090 — Cognitionist Office Profile and Connection Contract

Status: admitted bounded Office Profile and provider-neutral contract.

## Decision

Admit Cognitionist as the shared Office stewarding Cognitive Ports, Models,
Model Adapters, compatibility evidence, credential-requirement requests, and
candidate Cognitive Session plans under Core Doctrine v6 and Lexicon v4.

Cognitionist may validate exact current ports, register and admit evidenced
adapters, request bounded credential access from Locksmith, and hand a candidate
session plan to Master Mason. It may not store, reveal, resolve, rotate, revoke,
or validate credentials; execute tools; start Runtime; select a provider by
institutional preference; determine semantic correctness; judge findings; or
authorize external action.

Connection requests derive their port reference from the presented governed
port artifact. Adapter admission does not activate a session. Session plans
remain `CANDIDATE`, carry only an opaque credential-lease reference, and record
`liveSessionCreated: false`.
