# DR-087 — Imperium Lexicon v4 Cognitive-Medium Vocabulary

Status: enacted current canonical vocabulary.

## Decision

The Senate enacts `imperiumlexicon-core-v1@4`, superseding v3 and adding six
normalized terms: Cognitionist, Cognitive Port, Cognitive Medium, Model Adapter,
Model, and Cognitive Session. The definitions separate cognition capability
from authority, credential custody, semantic correctness, and Runtime execution.

Mandatory revalidation applies to Cognitionist, Officer cognitive ports,
Runtime, and Locksmith boundaries. No provider, model, credential mechanism, or
live session is selected or authorized.
