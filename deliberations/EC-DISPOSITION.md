# EC-DISPOSITION — Exemplar-Grounding Correction Lineage

## Purpose

This file records the disposition categories for correction proposals that are not the active EC-CURRENT standard.

- **EC-CURRENT**: active correction state and admitted standards.
- **Deferred EC**: identified correction work not yet defined or admitted.
- **Closed EC**: considered and explicitly not admitted as a current doctrine.
- **Historical EC records**: numbered decisions, assessments, and pressure tests retained for provenance.

A deferred or closed correction is not an active standard. Historical records must not be read as current authority when EC-CURRENT provides a later disposition.
