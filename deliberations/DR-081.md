# DR-081 — Enact Imperium Lexicon v3 Semantic Closure

Senate enacts `imperiumlexicon-core-v1@3`, superseding v2. V3 replaces generic metadata across all prior entries with definition-bound permitted use, prohibited interpretation, examples, counterexamples, and revision conditions. It admits 28 consequential terms previously used inside definitions without canonical entries, producing 84 active entries.

Mandatory revalidation applies to all surfaces. Bounded closure concerns the current post-reset constitutional and reconstructed-Office vocabulary; future concepts still require Senate petition.
