# Guildhall Profession Resolution Conformance Plan 001

## Status

Draft plan exercised by fifteen theoretical pressures and twelve cross-layer convergence checks.

## Conformance Axes

| Axis | Required behavior |
|---|---|
| Native owner | Guildhall retains Profession Specification meaning and resolution |
| Exact inputs | one Mission Identity, Mission Need version, and approved Work Specification version |
| Work fidelity | professional truth does not rewrite mission or work meaning |
| Professional fit | profession identity follows required capability, judgment, domain, evidence, and risk |
| Practice boundary | required competence and legitimate limits are explicit |
| Adjacency | adjacent, contributory, and excluded professions remain distinct |
| Operator constraint | a suggested profession remains subject to fit validation |
| Ambiguity | competing or irreducibly multiple professions remain explicit |
| Findings | conformant, refused, and unresolved remain distinct |
| Provenance | exact derivation, citation, and supersession remain PB-001-owned |
| Revision | semantic changes require a new assessment and invalidate stale search eligibility |
| Handoff | exact conformant Profession Specification becomes eligible for Garrison search |
| Persona boundary | no Canonical Persona is selected, forged, tested, admitted, or recruited |
| Procedure boundary | resolution eligibility does not trigger search or referral automatically |
| Regression | admitted production meanings remain unchanged |

1. require 15 / 15 corrected profession-resolution pressures
