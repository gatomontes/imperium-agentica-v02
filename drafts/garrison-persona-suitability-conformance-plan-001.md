# Garrison Persona Suitability Conformance Plan 001

## Status

Draft plan exercised by fifteen theoretical pressures and twelve cross-layer convergence checks.

## Conformance Axes

| Axis | Required behavior |
|---|---|
| Native ownership | Guildhall applies suitability; Garrison supplies inventory truth |
| Exact inputs | one Profession Specification version, finding, criteria set, and inventory view |
| Inventory identity | every candidate identity, version, status, and source record is exact |
| Eligibility | admission, qualification, availability, and non-terminal status are all required |
| Criterion evidence | every mandatory suitability criterion has an explicit result and evidence |
| Boundary fidelity | professional competence, doctrine, traits, and limits are not inferred or rewritten |
| Multiplicity | zero, one, and multiple candidate outcomes remain explicit |
| Findings | candidates found, no suitable persona, and unresolved remain distinct |
| Blocking | stale, mismatched, partial, contested, or missing evidence cannot proceed |
| Provenance | exact citation, correlation, search derivation, and supersession remain PB-001-owned |
| Revision | source or inventory changes invalidate stale search results |
| Found branch | eligible candidates do not become a selected or reserved persona |
| No-match branch | branch eligibility does not construct, test, or admit a persona |
| Procedure boundary | neither branch executes automatically |
| Regression | admitted production meanings remain unchanged |

## Merge Gate

1. require 15 / 15 corrected persona-suitability pressures
2. require 12 / 12 cross-layer convergence checks
3. require Runtime successor regression 91 / 91
4. require repository regression PASS
5. verify zero production semantic files changed
6. verify inventory truth, suitability, selection, construction, testing, admission, and recruitment remain distinct
7. verify no Authority grant, Procedure transition, Runtime behavior, deployment, or external effect

## Non-Goal

Passing this plan does not query a live registry, select or reserve a persona, start persona construction, admit a persona, recruit an Operative, or admit production semantics.
