# Conscription Selection And Recruitment Conformance Plan 001

## Status

Draft plan exercised by fifteen theoretical pressures and twelve cross-layer convergence checks.

## Conformance Axes

| Axis | Required behavior |
|---|---|
| Entry | exact current suitable-candidate set plus exact mission and deployment-medium inputs |
| Native ownership | Guildhall owns suitability; Garrison owns inventory; Conscription selects and recruits |
| Selection | one exact candidate is chosen only by explicit applicable criteria |
| Multiplicity | ties and missing material criteria remain unresolved rather than arbitrary |
| Currency | changed candidate, inventory, suitability, work, profession, or medium inputs invalidate downstream use |
| Medium fit | target-specific compatibility is evaluated without redefining professional suitability |
| Construction | one immutable Operative version is derived from one selected Canonical Persona version |
| Preservation | competence, doctrine, applicable traits, constraints, and refusal behavior remain explicit |
| Deviation | every forced deviation is recorded, dispositioned by its native contract, or blocks recruitment |
| Findings | conformant, refused, and unresolved outcomes remain distinct for selection and recruitment |
| Repair | defects return to the native owner and semantic change creates a new version |
| Provenance | PB-001 correlation, derivation, transformation, citation, production, and supersession remain complete |
| Authority | applicable creation references are cited or explicitly not applicable; no grant is inferred |
| Handoff | recruitment conformance remains separate from A0 handoff conformance and Muster readiness |
| Regression | admitted production meanings remain unchanged |

## Merge Gate

1. require 15 / 15 corrected selection-and-recruitment pressures
2. require 12 / 12 cross-layer convergence checks
3. require preserved Runtime successor regression 91 / 91
4. require repository regression PASS
5. verify zero production semantic files changed
6. verify candidate eligibility, selection, recruitment, handoff, mission assembly, and deployment remain distinct
7. verify no live reservation, Authority grant, Procedure transition, Runtime behavior, or external effect

## Non-Goal

Passing this plan does not select or recruit a live persona, instantiate an Operative, declare handoff conformance, assemble a mission, activate, or deploy anything.
