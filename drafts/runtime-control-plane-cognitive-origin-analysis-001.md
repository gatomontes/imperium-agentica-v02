# Runtime Control-Plane Cognitive-Origin Analysis 001

## Status

Investigation complete.

No Cognitive production change is proposed or admitted.

## Question

Who is responsible for:

- assessing a Control-Plane Plan
- judging semantic-mapping compatibility
- deciding whether deployment, activation, migration, rollback, or recovery should be attempted
- reconciling an indeterminate control-plane effect
- presenting the exact action for Authority evaluation
- preserving unresolved operational risk

Runtime can execute and observe these actions.

Authority can permit them.

Neither can supply the substantive judgment or responsibility.

## Existing-Origin Review

### Chief of Staff

Native responsibility is Curia information, counsel, record, and mission-decision handoff.

Control-plane engineering judgment is not Curial orchestration.

Disposition: **DO NOT ABSORB**.

### CEO / Curia

Native responsibility is bounded mission judgment under an Executive Mandate.

A Runtime deployment or mapping migration may affect the platform across missions and does not automatically belong to one Curia Session.

Disposition: **DO NOT ASSUME**.

### Muster

Native responsibility is mission-specific outbound assembly, operationalization, and Operative-binding release.

Muster explicitly must not become the unnamed execution layer.

Disposition: **DO NOT ABSORB**.

### Armory

Native responsibility concerns tools supplied to missions.

Runtime implementation deployment and state migration are not mission tool issuance.

Disposition: **DO NOT ABSORB**.

### Locksmith

Native responsibility concerns credentials, access bindings, and provider access.

Credential-loading mechanics intersect with Locksmith but do not transfer deployment, compatibility, rollback, or recovery judgment.

Disposition: **INTERSECTION ONLY**.

### External Operator

The operator may presently perform the judgment outside Imperium and may be the represented Principal or grantee when the applicable Authority Basis exists.

That is a viable development-time arrangement.

It does not prove that Runtime itself owns the judgment, and it does not define an internal responsibility for later delegated or autonomous operation.

Disposition: **VALID EXTERNAL SOURCE; NOT AN INTERNAL COGNITIVE CONTRACT**.

## Minimal Candidate Responsibility

The evidence supports investigation of one functionally named Cognitive responsibility, not an institution:

```text
Runtime Control-Plane Responsibility
```

Candidate burden:

- assemble the Control-Plane Situation
- evaluate plan completeness and semantic compatibility
- identify affected missions, artifacts, resources, and credentials
- request specialized counsel when required
- select or recommend an exact bounded disposition
- expose uncertainty and irreversible consequences
- preserve distinction between technical feasibility and Authority
- hand only an authorized instruction to Runtime
